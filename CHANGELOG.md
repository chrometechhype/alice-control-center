# Changelog

Все заметные изменения Alice Control Center. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0-alpha.7] — 2026-10-29

Выпуск про сценарии и порядок на экранах: триггеров стало тринадцать вместо четырёх, «Сброс» в LED
возвращает кольцо туда, где оно было, а не удалённый пресет, и экраны без связи больше не состоят из
одной пустоты.

### Добавлено

- **Тринадцать триггеров сценариев.** `manual`, `app.start`, `device.connect`, `device.disconnect`,
  `station.reboot`, `update.available`, `metrics`, `schedule`, `interval`, `volume`, `wifi`,
  `bluetooth`, `scenario.done`. У каждого свой конфиг: порог метрики с направлением сравнения,
  время `HH:MM` и дни недели, период в минутах, пересечение громкости, событие Wi-Fi
  (`connected`/`disconnected`/`changed`) с фильтром по SSID, подключение и отключение Bluetooth с
  фильтром по MAC или имени, цепочка «после сценария N» с пропуском при неудаче.
- **Релиз как событие.** Проверка обновлений объявляет новый релиз ровно один раз
  (`update.available`), поэтому сценарий не срабатывает на каждом фоновом опросе.
- **Отдельный экран без связи.** `OfflineState` показывает, что именно делает этот раздел, даёт
  «Повторить подключение» и «Мастер подключения» и три подсказки, что проверить.

### Исправлено

- **«Сброс» в LED Studio и Fun Lab (#2).** Точка восстановления больше не берётся из
  `data/led-state.json`: панель снимает её с самого кольца перед стартом эффекта (`trigger` и
  `brightness` каждого канала `/sys/class/leds/plum:*`). Если кольцо было под штатной индикацией
  Алисы, «Сброс» возвращает штатную индикацию; если погашено — оставляет погашенным. После конца
  анимации состояние кольца перечитывается, а сообщение говорит, что именно произошло: цвет до
  эффекта, штатная индикация или выключенное состояние.
- **Обновление теряло `+x` у `start.sh` (#3).** ZIP не хранит Unix-права, поэтому после копирования
  файлов панель выставляет `0o755` всем `.sh` в корне и в `scripts/`. Обновление теперь запускает
  `apply-update.mjs` из свежераспакованного архива, а не из установленной копии — иначе исправление
  заработало бы только через релиз; установленный скрипт остаётся запасным вариантом.
- **Журнал событий больше не растягивается на 16 000 px.** Повторы одного события склеиваются по
  всему окну, а не только по соседним строкам: у каждой строки счётчик и время последнего повтора,
  на странице 60 строк и кнопка «Показать ещё».
- **Обзор без дубля.** Карточка «Нет активного подключения» больше не повторяет герой-блок: действия
  переехали в него самого, ошибка подключения показывается один раз.
- **Кнопки заголовка не переносятся при 1280.** Действия страницы держатся в одну строку, а длинное
  описание переносится первым.
- **Боковое меню помещается при 1080.** Пункты и заголовки групп компактнее, у прокрутки появился
  плавный край и подсказка, что ниже есть ещё пункты.

### Изменено

- **Панель без связи** — одна карточка вместо центрированной пустоты на девяти экранах: LED, Fun Lab,
  звуки, Bluetooth, Wi-Fi, автоматизация, терминал, файлы, плагины и системный монитор.
- **Настройки** — блок «Доступ и безопасность» с заголовком и статусом вместо голого списка пар
  «ключ — значение»; тема переключается подписью «как в системе»; на широком экране колонки
  выровнены по высоте.
- **Файлы** — путь в списке корней обрезается по ширине и не заезжает под метку `rw`/`ro`.

### Качество

- 200 тестов в 17 файлах. В `tests/ledState.test.ts` — чтение кольца до эффекта, возврат к штатной
  индикации, погашенное кольцо и регрессия «старый пресет не воскресает»; в `tests/automation.test.ts`
  — все тринадцать триггеров и цепочки между сценариями.
- `npm run typecheck` и `npm run build` проходят; все пятнадцать маршрутов панели открываются без
  ошибок в консоли, проверены на 760, 1280, 1440 и 1920 px.

## [1.0.0-alpha.6] — 2026-10-29

Выпуск про интерфейс и диагностику: графитовая тёмная тема без цветных примесей, Wi-Fi на
`wpa_supplicant`, одновременно запускаемые шаги сценария, живой пикер цвета для LED и полная
отладка системы одной командой.

### Добавлено

- **Wi-Fi на главном экране.** Карточка обзора показывает, к какой сети подключена станция, и её
  настоящий пароль (`psk`), прочитанный из `/bkupgrade/data/wpa_supplicant.conf`. Пароль скрыт за
  «глазом» и копируется одной кнопкой; рядом — IP, тип шифрования, частота и путь к конфигу.
- **Вкладка Wi-Fi на `wpa_cli`.** Сканирование эфира через `scan`/`scan_results`, подключение к новой
  точке и переключение между сохранёнными: панель правит `network={…}` в конфиге, сохраняя чужие
  блоки байт в байт, и применяет его через `wpa_cli -i wlan0 reconfigure` + `reassociate` — без
  перезагрузки колонки. Если `wpa_cli` на прошивке нет, вкладка честно говорит об этом, а не
  выдумывает список сетей.
- **Сценарий: до 32 шагов и одновременный запуск.** У каждого шага появилось «Выполнять
  одновременно с шагом N»: связанные шаги попадают в одну группу и стартуют в одном тике через
  `Promise.all`, поэтому кольцо и голос срабатывают вместе, а не друг за другом.
- **Озвучка голосом Алисы.** «Сказать» и шаг сценария `say` больше не ходят в сторонний TTS: панель
  отправляет фразу в штатный речевой сервис станции (`AliceCapability` → `START_VOCALIZE` на
  `127.0.0.1:9875`) по SSH-каналу. Станция синтезирует её в облаке Яндекса и играет своим плеером —
  файлы не создаются, ИИ-провайдер и голосовые ключи не нужны. Фразы выполняются по очереди, чтобы
  два запроса не перемешались в одном сокете; при отсутствии `socat`/`nc` или недоступном IPC панель
  прямо называет причину. Конец фразы определяется по состоянию речи станции (события TTS, а где их
  нет — кадр начала/конца проигрывания), поэтому подтверждённая озвучка больше не выглядит таймаутом.
- **Полная отладка `--full-debug`.** `start.bat --full-debug`, `npm run debug:full` или
  `./full-debug.sh --full-debug` собирают отчёт `data/reports/full-debug-<дата>.txt`: журналы ядра и
  демонов, ошибки/OOM/segfault, процессы Quasar и YAM из `/proc`, дамп ОЗУ (`meminfo`, `vmstat`,
  `buddyinfo`, `zoneinfo`, топ процессов по RSS), скорость диска через `dd`, сеть, Bluetooth и
  `wpa_supplicant.conf` со статусом `wpa_cli`. Каждая секция выполняется отдельно, пароли Wi-Fi
  маскируются, пароль SSH не печатается.

### Изменено

- **Тёмная тема — чистый графит.** Подложка `#0b0c0e`, карточки `#131417`, боковое меню и топбар без
  синевы и фиолетового оттенка; акцент корпуса станции остаётся только в кнопках и иконках. Заодно
  исправлена причина, по которой тема «светлела»: блок акцента и `[data-theme='dark']` имели
  одинаковую специфичность, и светлые подложки с примесью акцента перекрывали графит.
- **LED Studio: кольцо само открывает пикер.** Клик по кольцу зоны открывает системный выбор цвета
  (`showPicker()` с запасным `click()`), под кольцом виден выбранный HEX — больше не нужно целиться в
  маленький квадрат.
- **Пресет LED — это эффект.** После применения пресета «Сброс» возвращает кольцо к цвету, который был
  до него, а не к самому пресету.
- **Настройки ИИ больше не обещают чужой голос.** Поля «Модель озвучки» и «Голос» убраны: озвучка —
  голос Алисы через станцию, а ИИ-сервер отвечает только за текст Fun Lab и сценариев.

### Исправлено

- **Bluetooth: подключение к отдельному устройству.** `pair` без агента BlueZ молча падал. Теперь одна
  интерактивная сессия `bluetoothctl` регистрирует `NoInputNoOutput`-агента, делает `trust`, при
  необходимости `pair`, затем `connect`, а результат проверяется по `info`; при `host is down`
  панель один раз сканирует эфир и повторяет попытку.
- **Станция Мини 2 с часами (#1).** Модель больше не определяется как «первая Мини»: добавлены
  отдельные виды «Станция Мини 2» и «Станция Мини 2 с часами». Для часов и LED-дисплея панель честно
  объясняет, что ими управляет прошивка и `sysfs`-кольца у этой модели нет, вместо обещания
  управления, которого не будет.
- **Понятный отказ SSH.** «Timed out while waiting for handshake» превратилось в «Колонка не
  ответила на SSH-рукопожатие: проверьте адрес, порт и что станция включена».

### Качество

- 179 тестов в 17 файлах: новые проверки сессий Bluetooth, определения «Мини 2 с часами»,
  `tests/fullDebug.test.ts` — маскировка `psk`, продолжение после упавшей секции и разметка отчёта, а
  также `tests/aliceVoice.test.ts` — побайтовое совпадение кадров со эталоном, разбор событий
  `TTS_STARTED`/`TTS_COMPLETED`/ошибки и очередь фраз.
- `npm run typecheck` и `npm run build` проходят; тёмная тема проверена в браузере: подложка, карточки
  и сайдбар остаются графитовыми и при включённом акценте корпуса.

## [1.0.0-alpha.5] — 2026-10-28

Панель больше не путает альфы между собой: `1.0.0-alpha.3` и `1.0.0-alpha.4` теперь разные версии.

### Исправлено

- **Сравнение версий учитывает суффикс `-alpha.N`.** Парсер отбрасывал всё после патча, поэтому все
  `1.0.0-alpha.N` считались одинаковыми: панель на alpha.3 отвечала «установлена актуальная версия»,
  пока на GitHub лежала alpha.4, и не скачивала обновление. Теперь порядок по SemVer: `alpha.3` <
  `alpha.4` < `alpha.10` < `beta` < `1.0.0`, метаданные сборки игнорируются.
- **Тост после проверки больше не врёт.** «Установлена актуальная версия» показывается только когда
  номера действительно совпадают; иначе появляется «Доступна версия …» и кнопка установки.

### Важно для обновления

Исправление живёт в самой панели, поэтому панели на alpha.1–alpha.4 не могут обновиться до alpha.5
изнутри — их нужно один раз обновить установщиком:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

Начиная с alpha.5 автообновление между альфами работает.

### Качество

- 129 тестов в 15 файлах; шесть новых в `tests/updateVersion.test.ts` проверяют порядок альф, числовые
  идентификаторы (`alpha.10` > `alpha.9`), приоритет релиза над пререлизом и метаданные сборки.

## [1.0.0-alpha.4] — 2026-10-28

«Сброс» после случайного цвета в Fun Lab больше не рапортует об успехе, оставляя кольцо светиться.

### Исправлено

- **«Сброс» после случайного цвета.** Случайный цвет сохранялся как «последние цвета» панели, и
  «Сброс» добросовестно возвращал именно его — снаружи это выглядело как «нажал, а цвет остался».
  Теперь перед началом любого эффекта панель запоминает состояние кольца до него и возвращает именно
  его; повторные нажатия «Случайный цвет» не сдвигают эту точку. Осознанное применение цвета в LED
  Studio, «Выключить», «Включить» и «Штатный режим» закрывают эффект — новым «до» становится это
  состояние. Кнопки «Стоп» и «Сброс» при этом больше не обещают успех заранее.
- **Честный отказ без связи.** Если колонка недоступна, «Сброс» сообщает об ошибке, а не «эффект
  сброшен», когда на самом деле на кольцо ничего не записалось.

### Качество

- 123 теста в 14 файлах: четыре новых проверяют точку восстановления — возврат вместо цвета эффекта,
  сохранение первой точки, сброс после осознанного действия и запасной путь без эффекта.

## [1.0.0-alpha.3] — 2026-10-28

Проверка обновлений больше не зависит от `api.github.com`: если API заблокирован провайдером или
недоступен, панель берёт номер релиза со страницы `github.com/<repo>/releases/latest` и качает архив
оттуда же.

### Исправлено

- **Обновления на сетях, где закрыт GitHub API.** Некоторые провайдеры отдают ошибку на
  `api.github.com`, хотя сам `github.com` открывается. Раньше карточка «Обновления» в этом случае
  показывала «нет связи» и не видела новые версии. Теперь проверка идёт по веб-странице релиза: тег
  берётся из адреса после перенаправления, архив — из `releases/download/<тег>/Alice-Control-Center-<версия>.zip`,
  заметки — из `docs/release-notes/` репозитория. SHA-256 по-прежнему обязателен: без него установка
  отменяется.
- **Ошибка называет причину.** Если недоступны оба адреса, панель показывает код сети (`ENOTFOUND`,
  `timeout` и т. п.) и подсказывает про VPN, а в карточке появилась ссылка на страницу релизов.
- **Установщик умеет то же самое.** При недоступном API `install.ps1` определяет последний тег по
  перенаправлению `github.com/.../releases/latest` и сам собирает ссылки на архив и контрольную сумму.

### Обновление с 1.0.0-alpha.1 и alpha.2

Если панель видит обновления — «Настройки» → «Обновления» → «Установить». Панель на alpha.1, у которой
API был заблокирован, новую версию проверить ещё не может: её нужно один раз обновить установщиком
(или скачать ZIP со страницы релизов и распаковать поверх установки).

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

## [1.0.0-alpha.2] — 2026-10-28

Связь со станцией теперь стабилизируется на стороне панели: частота опроса и темп переподключений
подстраиваются под то, как колонка себя ведёт, вместо фиксированных двух секунд.

### Добавлено

- **Система стабилизации связи.** Панель считает обрывы за последние 3 минуты и держит один из трёх
  режимов: `stable`, `strained` (2 обрыва) и `unstable` (4 обрыва). В `strained` опрос замедляется до
  8 с, в `unstable` — до 20 с; разброс интервала только вверх, чтобы панель не совпадала по фазе с
  циклом обновления колонки и не мешала ей именно в момент, когда та перегружена.
- **Демпфер переподключений.** Задержки лестницы растягиваются на нестабильной связи (×1,5 в
  `strained`, вдвое с полом 5 с в `unstable`, потолок 45 с) и получают разброс ±15 %, чтобы две панели
  или панель и колонка не бились в одну и ту же секунду.
- **Экономия поиска станции.** Поиск по сети идёт раз в 45 с, а после двух пустых циклов — раз в 120 с;
  полный опрос /24 не чаще одного раза в 20 с. Раньше выключенная колонка заставляла сканировать
  подсеть каждые несколько секунд без всякой пользы.
- **Режим виден в интерфейсе.** Плашка статуса при нестабильной связи объясняет причину: «Колонка
  перегружена: обрывов за 3 мин — 4. Панель опрашивает её раз в 21 с…», а не просто «Подключено».
- **LED: проверка записи и карта зон.** После каждой команды панель перечитывает `brightness` всех
  каналов и называет не принявшие значение (`зона 2 · green`), а в статусе показывает каналы, которых
  на прошивке нет. «Проверить кольца» зажигает зоны по одной — красный, зелёный, синий, — чтобы номер
  зоны совпадал с физическим кольцом.
- **LED: включение и сброс.** LED Studio и Fun Lab помнят состояние кольца: «Выключить» гасит его,
  «Включить» возвращает цвета, которые горели до выключения, а «Сброс» останавливает эффект и
  возвращает цвет до анимации вместо последнего кадра.

### Изменено

- **Списки прокручиваются внутри карточек.** Звуки, файлы, команды терминала и Bluetooth-устройства
  больше не растягивают страницу на несколько экранов; форма публикации звука открывается окном.
- **Меньше дублирующих блоков.** Убраны вторая карточка «Контроллер» в Bluetooth, отдельная карточка
  групп в терминале, дубль подсказок на странице файлов и карточка «О приложении» в настройках.
- **Опрос метрик не греет станцию.** Панель больше не опрашивает колонку каждые 2 секунды: базовый
  интервал поднимается по режиму, а интервал метрик переключается на лету, без остановки сбора.
- **Задержка чтения учитывается.** Время каждого замера попадает в статистику: медленные ответы
  видны отдельно от обрывов.

### Исправлено

- Фиксированные 2 с опроса на прошивке, которая сама перезагружается, держали канал занятым почти
  постоянно — теперь панель в таком состоянии сама уходит на 20 с.

## [1.0.0-alpha.1] — 2026-10-27

Первый альфа-выпуск. Панель больше не притворяется сломанной, когда колонка сама рвёт SSH, говорит
там, где ИИ-провайдер молчит, и показывает правду о сопряжении Bluetooth.

### Добавлено

- **Озвучка системным голосом Windows.** Если у ИИ-провайдера нет `/audio/speech`, панель синтезирует
  речь через SAPI — русский голос выбирается сама — и отдаёт на колонку готовый WAV 48 кГц. Голос
  Алисы синтезируется на сервере Яндекса, и панель его не подменяет: об этом написано прямым текстом
  в Fun Lab, Sound Studio и «Настройках».
- **Генерация сценариев.** `/api/ai/scenario` собирает пошаговый сценарий (кольцо, озвучка, звук,
  пауза, диагностика) из описания. Жёсткий промпт требует настоящие шаги, а не пересказ просьбы.
- **Шкала громкости Алисы.** Регистр `Master` пересчитывается по таблице прошивки, поэтому
  «уменьши громкость» и ползунок показывают одно число, а не процент ALSA.
- **Проверка типов backend.** `npm run typecheck` покрывает `server/**`, и `npm run build` не
  соберётся, если сервер не компилируется. Раньше backend не проверял никто.

### Исправлено

- **Обрыв связи больше не ломает интерфейс.** Станция прерывает свой SSH-транспорт каждые несколько
  минут, и запрос, попавший в это окно, отвечал сырым текстом ssh2 («Unable to exec») или
  «Устройство не подключено». Теперь чтение статуса ждёт лестницу переподключения, повторяет
  оборванный запрос один раз и только потом сдаётся честной фразой «Колонка не отвечает. Панель
  пытается связаться с ней — попробуйте через несколько секунд».
- **Экраны не гаснут на время переподключения.** Если колонка хотя бы раз ответила в этой сессии,
  разделы держат свои данные, а в шапке светится «Переподключение…».
- **Bluetooth: правда о сопряжении.** `devices` показывает кэш последних поисков, а не связанные
  устройства. Панель читает `devices Paired` и делит список на «сопряжено навсегда» и «только в кэше
  поиска»; для несвязанного устройства кнопка теперь «Сопрячь и подключить».
- **Сканирование Bluetooth не рвёт SSH.** Десятисекундный `scan on` держал канал и совпадал со
  смертью транспорта; теперь сканирование запускается на колонке отсоединённым процессом, а панель
  только читает список.
- **Ошибки подключения — по-русски и с подсказкой.** «Device … not available» превращается в
  «наушники спят в кейсе, далеко или подключены к телефону».
- **LED и ИИ не врут про железо.** Пока колонка недоступна, панель не заявляет «на этой модели не
  обнаружены LED-зоны» — сначала дожидается связи.
- **Библиотека звуков.** Папки `ru-RU` / `ar-EG` / `common` называются по-русски, системные звуки
  отличаются от своих, свои удаляются — в том числе с кириллицей в имени.
- **Файлы.** Проводник предлагает каталоги, которые на этой прошивке действительно есть.

### Изменено

- Действия (воспроизведение, публикация, удаление, терминал, громкость, LED) ждут связи до 20 секунд
  вместо мгновенного «не подключено».
- Степень зрелости теперь видна в версии, а не в флаге GitHub: альфа-тег публикуется как обычный
  релиз, поэтому автообновление предлагает её так же, как стабильную версию.

## [0.3.1] — 2026-10-27

### Исправлено

- **Панель залипала в «Ошибка» после неудачного запуска.** Лестница переподключения не стартовала,
  если первая попытка не удалась: панель показывала «Ошибка» и ждала нажатия «Переподключиться».
  Причина — попытка всё ещё занимала слот подключения, а лестница отказывается запускаться, пока слот
  занят. Теперь она стартует сразу после освобождения слота, поэтому запускается при любом неудачном
  `connect()`, включая ту первую попытку, что стартует вместе с панелью.
- **Колонка находится без сохранённого MAC.** Прежняя логика «переехать» на новый IP требовала MAC, а он
  сохранялся только после успешного подключения — замкнутый круг для станции, перерутенной на другой
  адрес. Теперь без MAC панель опознаёт станцию в сети (mDNS, ARP и опрос портов) и принимает её адрес,
  когда на выбор ровно один SSH-хост; при большем количестве адрес предлагает выбрать в мастере.
- **Переезд учитывает порт.** В конфиг пишется и порт, а запись в журнале читается как «Колонка найдена
  в сети: 192.168.1.100:2222 → 192.168.1.42:2222» с указанием причины — MAC или SSH-баннер.
- **Опрос сети успевает обойти /24.** mDNS забирает первые 2,5 секунды, и на опрос портов оставалось
  меньше секунды — станция не находилась. Опрос при переезде получает полные 6 секунд.

## [0.3.0] — 2026-10-27

### Добавлено

- **Поиск колонки в сети.** «Мастер подключения» опрашивает mDNS, таблицу ARP и SSH-порты `22` и
  `2222` по всем локальным /24-сетям и сам подставляет адрес, порт и пользователя. Вводить IP руками
  больше не нужно.
- **Переподключение по MAC-адресу.** Панель запоминает MAC и device ID станции. Если DHCP выдал
  колонке новый адрес, ACC находит её по MAC, обновляет сохранённый IP и пишет об этом в журнал.
- **Озвучка.** «Играть на станции» проигрывает уже существующий системный звук без всякой записи,
  «Сказать на колонке» синтезирует речь через `/audio/speech`, кладёт клип в `/tmp`, проигрывает его и
  удаляет той же командой — на станции ничего не остаётся. Модель и голос озвучки задаются в карточке ИИ.
- **Доступ с телефона при раздаче Wi-Fi.** Карточка показывает адреса всех интерфейсов и помечает тот,
  который находится в одной сети со станцией; рядом — диагностика брандмауэра Windows и кнопка
  «Разрешить порт в брандмауэре» (запрос UAC, правило TCP только для частной сети).
- **Стабильная генерация LED-сцен.** ИИ присылает рецепт сцены (эффект, палитра, число кадров, fps,
  интенсивность), а кадры считает панель — сотни пикселей в ответе больше не обрезаются лимитом
  токенов. Включён `response_format: json_object` с откатом для серверов, которые его не знают.
  Ответ разбирается терпимо: рассуждения перед JSON, оборванный на середине объект и даже пример
  схемы, продублированный внутри ответа, больше не повод сдавать сцену; недостающие числа панель
  подставляет сама. Плюс один автоматический «ремонт» действительно битого ответа.
- **Описание релиза в интерфейсе.** Баннер обновления и карточка «Обновления» показывают список
  изменений, дату релиза и размер архива вместо сырого markdown.

### Изменено

- Переподключение больше не упирается в тупик: после четырёх быстрых попыток панель ищет колонку
  каждые 45 секунд, а не ждёт ручного нажатия. Параллельные подключения (авто, старт, ручное)
  сериализованы — раньше они рвали сокет друг друга и выглядели как «вечное переподключение».
- Обзор стал компактнее: из героя убраны дубли — крупная «Алиса», строка «OS · ядро», чипы
  Quasar/arch/IP/Uptime/Wi-Fi и подпись под портретом. Всё это уже есть в карточках метрик и «Устройство».
- Название панели живёт в боковой панели; вторая копия заголовка из топбара убрана.
- Разделы перегруппированы: «Обзор», «Станция», «Инструменты», «Панель». Карточки настроек идут в
  порядке подключение → доступ с телефона → интерфейс → образ станции → ИИ-генератор → обновления.
- Обложки сцен в Fun Lab выровнены: одинаковая высота превью, заголовок в одну строку с многоточием,
  описание не длиннее трёх строк.

### Исправлено

- «Установлено 0.2.3 / Последняя 0.2.3» с кнопкой «Установить 0.2.3»: доступность обновления бралась
  из кэша и не пересчитывалась при совпадении версий. Теперь статус считается по живой версии, а
  кэши, записанные старыми сборками, дополняются полем `highlights`.
- `api.get` игнорировал таймаут, поэтому долгий поиск в сети показывал ошибку раньше времени.
- Проверка типов сервера падала на подписке обработчика `close` в SSH-адаптере.

### Исправлено

- Проверка ИИ-модели больше не выбрасывает из панели. Отказ ключа ИИ-сервера отдавался как
  HTTP 401, и frontend считал это истёкшей сессией доступа по локальной сети: показывал экран

  токена вызывается только по кодам `UNAUTHORIZED` и `BAD_TOKEN`.

- Пользовательские сцены выводятся над встроенными; таймаут отключается для любых сцен.

### Исправлено

- Статус проверки обновлений больше не показывает «актуально» при ошибке сети или отсутствии релизов.

- Сборка релиза больше не подхватывает тесты из распакованной папки `release/`.

### Безопасность

- Обновление принимается только по HTTPS, с проверкой SHA-256 и валидацией путей в ZIP.
- Архивы без контрольной суммы, с несовпадающей версией или небезопасными путями отклоняются.
- Пароль SSH и ключи ИИ остаются только в `data/config.json`; в публичный архив `data/` не входит.
