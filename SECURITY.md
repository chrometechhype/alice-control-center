# Security

Alice Control Center управляет рутованной станцией в локальной сети. Относитесь к ней как к
административной консоли, а не как к обычному сайту.

## Модель угроз

- По умолчанию backend слушает только `127.0.0.1`.
- LAN-доступ включается только явно и всегда требует токен.
- Браузер не получает пароль SSH, ключи ИИ и содержимое `data/config.json`.
- Backend проверяет входные данные, пути и команды; потенциально опасные действия требуют
  подтверждения.
- Обновления скачиваются только по HTTPS с GitHub и принимаются только при совпадении SHA-256.

Панель не предназначена для публикации в интернет, для многопользовательского хостинга или для
управления чужой станцией без разрешения владельца.

## Обязательные правила

- Не публикуйте root-доступ, SSH или ADB в открытый интернет.
- Не сохраняйте пароли в исходном коде, README, скриншотах и коммитах.
- Не копируйте приватные ключи в проект.
- Не добавляйте пароли в URL и не отправляйте их во frontend.
- Не выполняйте произвольные shell-команды через незащищённый HTTP endpoint.
- Проверяйте пути файлов от обхода каталогов.
- Не перезапускайте всю станцию автоматически.
- Не скачивайте и не запускайте случайные бинарники.
- Не устанавливайте ничего на колонку без необходимости.

## Секреты

`data/config.json` создаётся при запуске, содержит пароль SSH и ключи ИИ и не должен попадать в
git. Файл исключён через `.gitignore`; публичный ZIP собирается скриптом
`scripts/package-release.mjs`, который не копирует `data/` и проверяет архив на известные
приватные строки. Если вы публикуете форк, убедитесь, что ваши собственные адреса и секреты не
попали в README, скриншоты или журнал.

## Обновления

- Панель принимает только ZIP из последнего GitHub Release репозитория из `ACC_GITHUB_REPO`.
- Контрольная сумма обязательна: `asset.digest` GitHub или файл `.sha256`/`sha256sums.txt`.
- Проверяются HTTPS, размер, количество записей, пути внутри ZIP и версия `package.json`.
- Перед заменой файлов создаётся резервная копия; при ошибке выполняется откат.
- Папка `data/` при обновлении не изменяется.

## Счётчик запусков

Раз в пять минут работающая панель отправляет одну отметку во внешний публичный счётчик
(`abacus.jasoncameron.dev`). В отметке только факт запуска: ни данных о станции, ни адреса, ни
имени, ни идентификатора установки. По этим отметкам автор видит, сколько копий панели работает.
Выключателя нет — счётчик добровольцев показывал число согласившихся, а не число пользователей.

Номер последнего отправленного окна панель хранит у себя в `data/presence.json`, чтобы перезапуск
внутри тех же пяти минут не добавил вторую отметку. Это локальный файл, он никуда не уходит.
