# Alice Control Center 0.2.0

Первый публичный релиз локальной панели для рутованной Яндекс Станции.

## Главное

- **Обновления из панели.** ACC проверяет GitHub Releases, показывает баннер и устанавливает новую
  версию с проверкой SHA-256, резервной копией и откатом при ошибке.
- **Bluetooth для телефона.** Сопряжение, подключение, `trust`, удаление устройств и режим поиска
  (`discoverable`/`pairable`) с подтверждением.
- **ИИ-сцены Fun Lab.** Любой OpenAI-совместимый сервер: модель сама выбирает FPS и рисует кадры,
  панель проверяет сцену и сохраняет её в «Мои сцены».
- **Material You 3 Expressive.** Светлая, тёмная и системная темы, динамические акценты под цвет
  корпуса Алисы, официальные изображения станций.
- **GitHub и Telegram** — иконки в панели, исходники и релизы открыты.

## Установка

1. Скачайте `Alice-Control-Center-0.2.0.zip` и `Alice-Control-Center-0.2.0.zip.sha256`.
2. Проверьте SHA-256:

   ```bash
   sha256sum -c Alice-Control-Center-0.2.0.zip.sha256
   ```

   Windows:

   ```bat
   certutil -hashfile Alice-Control-Center-0.2.0.zip SHA256
   ```

3. Распакуйте и запустите `start.bat` (Windows) или `./start.sh` (macOS/Linux).
4. Откройте http://127.0.0.1:8722 и пройдите мастер подключения.

Нужен Node.js 20+ и root-SSH на станции. Пароль хранится только в `data/config.json` на вашем
компьютере.

## Обновление с 0.1.0

Откройте «Настройки» → «Обновления» → «Проверить обновления». Если доступна 0.2.0, нажмите
«Установить»: панель скачает архив, проверит SHA-256, сохранит резервную копию и перезапустится.
Настройки, история, бэкапы и сцены в `data/` сохранятся.

## Безопасность

- Backend по умолчанию слушает только `127.0.0.1`.
- LAN-доступ включается явно и требует токен.
- Опасные операции требуют подтверждения.
- Обновления принимаются только с проверкой SHA-256 и безопасных путей в ZIP.
- Не публикуйте root-SSH и панель в открытый интернет.

## Известные ограничения

- Станция должна быть в одной сети с компьютером.
- Bluetooth-команды зависят от прошивки и `bluetoothctl`.
- Fun Lab требует настроенный OpenAI-совместимый сервер; без него доступны готовые сцены.
- 60 FPS — экспериментальный режим, возможна неравномерная работа кольца.

Полное описание — в [README](https://github.com/chrometechhype/alice-control-center#readme).
