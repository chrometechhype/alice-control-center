# Alice Control Center 1.0.0 Alpha 15

Выпуск про инструменты. ffmpeg, adb и OpenSSH больше не нужно искать по сайтам, распаковывать
руками и прописывать в PATH — панель скачивает их сама, одной кнопкой в мастере подключения.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=1.0.0-alpha.15)

## Добавлено

- **Кнопка «Скачать» вместо инструкции «добавьте в PATH».** В мастере подключения, в блоке
  «Инструменты», у отсутствующего инструмента появляется кнопка. Панель берёт официальную сборку,
  распаковывает из архива только нужные файлы в `data/tools` и сразу начинает ими пользоваться.
  Права администратора не нужны, PATH не трогается.
- **Своя копия важнее системной.** Если файл лежит в `data/tools`, панель берёт его, даже когда в
  PATH стоит другая версия: человек нажимает «Скачать» именно потому, что системная не работает.

Скачиваются три инструмента: **ffmpeg** (конвертация звуков для станции), **adb** (работа с
устройствами) и **OpenSSH** (подключение по SSH). Node.js идёт вместе с панелью и не качается.

## Почему так

Панель проверяла инструменты и на отсутствующий честно писала «установите в PATH». На Windows это
тупик: человек скачивает архив, не понимает, куда его распаковать, и получает ту же надпись снова.
Раз панель всё равно знает, какой файл ей нужен, проще скачать его самому.

## Как обновиться

Панель обновляет себя сама: «Настройки» → «Обновления» → «Проверить обновления» → «Установить».
Настройки, история, бэкапы и сценарии в `data/` сохраняются.

Установка с нуля:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

```sh
curl -fsSL https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.sh | sh
```
