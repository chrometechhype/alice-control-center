# Alice Control Center 1.0.0 Alpha 12

Выпуск про доступ. Токен доступа теперь ключ владельца на любом устройстве: телефон с ним умеет
то же, что компьютер с backend. А кнопка «Обновить» над цифрами репозитория больше не молчит,
когда GitHub упирается в лимит запросов.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=1.0.0-alpha.12)

## Добавлено

- **Токен доступа теперь даёт полный доступ.** Раньше часть действий работала только на
  компьютере, где запущен backend: посмотреть и перевыпустить токен, проверить сеть для телефона,
  добавить правило брандмауэра, показать QR-код и найти станцию в сети. С телефона они отвечали
  «доступно только с компьютера». Теперь любое устройство, вошедшее с токеном, управляет панелью
  наравне с этим компьютером. Токен — ключ владельца: не показывайте его посторонним и не
  пересылайте в мессенджерах.

## Исправлено

- **Обзор: «Обновить» над цифрами репозитория молчал.** Кнопка честно перезапрашивала GitHub, но
  при исчерпанной квоте (60 запросов в час на один адрес, лимит общий на адрес провайдера)
  сервер возвращал прошлые цифры без объяснений: «обновлено 20 минут назад» и ничего больше.
  Теперь кнопка пишет причину — «GitHub ограничил запросы (60 в час на адрес). Следующая попытка
  через 23 мин.» — и подтверждает успешное обновление. Часы обратного отсчёта берутся из ответа
  GitHub, а не из догадки.

## Как обновиться

Панель обновляет себя сама: «Проверить обновления» → «Установить». Настройки, история, бэкапы и
сценарии в `data/` сохраняются.

Установка с нуля:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

## Качество

- 229 тестов в 22 файлах; `npm run typecheck` и `npm run build` проходят.
- Живые проверки: кнопка «Обновить» в обзоре при исчерпанной квоте показывает «GitHub ограничил
  запросы (60 в час на адрес). Следующая попытка через 23 мин.»; `/api/insights?force=1` отдаёт
  эту причину в `refreshError` вместе с прошлым снимком; сетевой запрос с токеном проходит
  `requireAuth` без привязки к адресу.
