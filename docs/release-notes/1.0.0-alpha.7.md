# Alice Control Center 1.0.0 Alpha 7

Выпуск про сценарии и порядок на экранах. Триггеров стало тринадцать вместо четырёх, «Сброс» в LED
возвращает кольцо туда, где оно было, а не удалённый пресет, а панель без связи больше не показывает
пустой экран с одинокой карточкой по центру.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=1.0.0-alpha.7)

## Что нового

- **Тринадцать триггеров сценариев.** `manual`, `app.start`, `device.connect`, `device.disconnect`,
  `station.reboot`, `update.available`, `metrics`, `schedule`, `interval`, `volume`, `wifi`,
  `bluetooth`, `scenario.done`. У порога метрики — направление сравнения; у расписания — время
  `HH:MM` и дни недели; у интервала — период в минутах; у громкости — пересечение уровня; у Wi-Fi —
  событие `connected`/`disconnected`/`changed` с фильтром по SSID; у Bluetooth — подключение и
  отключение с фильтром по MAC или имени; у `scenario.done` — цепочка «после сценария N» с
  пропуском, если предыдущий упал.
- **Новый релиз — это событие.** Проверка обновлений объявляет найденную версию ровно один раз,
  поэтому сценарий на `update.available` не стреляет на каждом фоновом опросе.
- **Экран без связи стал полезным.** Вместо надписи «Колонка не отвечает» и пустоты — карточка с
  тем, что делает раздел, кнопками «Повторить подключение» и «Мастер подключения» и тремя
  подсказками: включена ли колонка, отвечает ли SSH, стоит ли подождать после перезагрузки.

## Исправлено

- **«Сброс» в LED Studio и Fun Lab (#2).** Причина была не в эффекте, а в точке восстановления: она
  читалась из `data/led-state.json`, где оставался пресет, уже удалённый с диска. Теперь панель
  снимает точку восстановления с самого кольца перед стартом эффекта — `trigger` и `brightness`
  каждого канала `/sys/class/leds/plum:*`. Кольцо под штатной индикацией Алисы возвращается к ней же,
  погашенное остаётся погашенным, а после конца анимации состояние перечитывается с кольца. Текст
  после «Сброса» прямо говорит, что произошло: вернули цвет до эффекта, штатную индикацию или
  выключенное состояние.
- **Обновление теряло `+x` у `start.sh` (#3).** ZIP не хранит Unix-права, поэтому после копирования
  файлов панель выставляет `0o755` всем `.sh` в корне проекта и в `scripts/`, а в логе обновления
  пишет, сколько скриптов поправила. Обновление запускает `apply-update.mjs` из свежераспакованного
  архива — иначе исправление заработало бы только через релиз; установленный скрипт остаётся
  запасным вариантом.
- **Журнал событий.** Повторы одного события склеиваются по всему окну, а не только по соседним
  строкам: у строки виден счётчик и время последнего повтора, на странице 60 строк и кнопка
  «Показать ещё». Журнал из 1331 записи занимал 16 000 px, теперь — одну страницу.
- **Обзор.** Карточка «Нет активного подключения» не повторяет герой-блок: действия переехали в него,
  ошибка подключения показывается один раз.
- **Кнопки заголовка.** Действия страницы остаются в одну строку на 1280 px, длинное описание
  переносится первым.
- **Боковое меню.** При 1080 px все пункты помещаются; у прокрутки плавный край, чтобы обрезанный
  пункт не выглядел артефактом.

## Как обновиться

Панель обновляет себя сама: «Проверить обновления» → «Установить». Настройки, история, бэкапы и
сцены в `data/` сохраняются.

Если `./start.sh` уже отвечает «Permission denied» после прошлого обновления, один раз выполните
`chmod +x start.sh` (или запустите `bash start.sh`) — дальше права сохраняет само обновление.

Установка с нуля:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

## Качество

- 200 тестов в 17 файлах. `tests/ledState.test.ts` проверяет чтение кольца до эффекта, возврат к
  штатной индикации, погашенное кольцо и регрессию «старый пресет не воскресает»;
  `tests/automation.test.ts` — все тринадцать триггеров и цепочки между сценариями.
- `npm run typecheck` и `npm run build` проходят; все пятнадцать маршрутов панели открываются без
  ошибок в консоли и проверены на 760, 1280, 1440 и 1920 px.
- Поведение LED проверено юнит-тестами на реальной раскладке sysfs; на живой колонке прогон не
  удался — 29.10 станция не отвечает по сети.
