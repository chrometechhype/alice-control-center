# Alice Control Center 0.2.2

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=0.2.2)

Обложка и документация: теперь сразу видно, что панель поддерживает всю линейку Яндекс Станций.

## Что нового

- Новая обложка с 12 моделями: Лайт, Лайт 2, Мини, Мини 3, Мини 3 Про, Мини с часами, Макс,
  Станция 2, Станция 3, Дуо Макс, Миди и Стрит.
- README: раздел «Поддерживаемые станции» с таблицей семейств и честной пометкой, что полный
  набор функций проверен на Лайт 2, а на остальных доступность зависит от прошивки.
- Актуальные инструкции по установке и обновлению.

## Установка с нуля

1. Скачайте `Alice-Control-Center-0.2.2.zip` и `Alice-Control-Center-0.2.2.zip.sha256`.
2. Проверьте SHA-256:

   ```bash
   sha256sum -c Alice-Control-Center-0.2.2.zip.sha256
   ```

   Windows:

   ```bat
   certutil -hashfile Alice-Control-Center-0.2.2.zip SHA256
   ```

3. Распакуйте и запустите `start.bat` (Windows) или `./start.sh` (macOS/Linux).
4. Откройте http://127.0.0.1:8722 и пройдите мастер подключения.

Нужен Node.js 20+ и root-SSH на станции. Пароль хранится только в `data/config.json` на вашем
компьютере.

## Обновление

«Настройки» → «Обновления» → «Проверить обновления». Панель скачает архив, проверит SHA-256,
сохранит резервную копию и перезапустится. Файлы в `data/` сохраняются.

## Безопасность

- Backend по умолчанию слушает только `127.0.0.1`.
- LAN-доступ включается явно и требует токен.
- Опасные операции требуют подтверждения.
- Обновления принимаются только с проверкой SHA-256 и безопасных путей в ZIP.
- Не публикуйте root-SSH и панель в открытый интернет.

Полное описание — в [README](https://github.com/chrometechhype/alice-control-center#readme).
