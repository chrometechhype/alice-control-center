# Alice Control Center 1.0.0 Alpha 11

Выпуск про цифры в обзоре владельца. Они перестали врать: счётчик запусков больше не спрашивает
согласия, «в сети» не падает до единицы каждые пять минут, «скачиваний» не удваивается файлами
контрольных сумм, а полоса не застывает на данных, снятых при открытии страницы.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=1.0.0-alpha.11)

## Изменено

- **Счётчик запусков включён у всех, галочки больше нет.** Настройка «Участвовать в статистике
  запусков» убрана. Панель раз в пять минут отправляет во внешний публичный счётчик одну
  анонимную отметку — без имени, адреса, модели станции и идентификатора установки. Счётчик
  добровольцев показывал число согласившихся, а не число пользователей, поэтому смысла в согласии
  не было.

## Исправлено

- **Обзор застывал на цифрах, снятых при открытии страницы.** GitHub отдаёт число скачиваний с
  задержкой в минуты, а панель держат открытой часами — новая версия вышла, а у неё по-прежнему
  ноль. Теперь цифры перечитываются каждые пять минут, а подпись «обновлено N минут назад»
  честно говорит, насколько они свежие.
- **«Скачиваний» считало и файлы контрольных сумм.** GitHub считает `ZIP` и `ZIP.sha256`
  отдельными скачиваниями, а панель забирает оба — каждое скачивание удваивалось. Теперь
  считаются только архивы панели: 94 вместо 136 на момент выпуска.
- **Цифры пропадали, когда GitHub упирался в часовой лимит запросов.** Лимит общий на адрес
  провайдера, а не на панель. Последний удачный снимок теперь хранится в `data/insights.json` и
  показывается вместе со своей датой, вместо того чтобы исчезать.
- **«В сети» падало до единицы каждые пять минут.** Панели отмечаются каждая в свой момент, а окно
  живёт пять минут — сразу после смены окна цифра показывала одну панель. И наоборот: перезапуск
  внутри окна отправлял новую отметку, поэтому перезапуски при правке кода выглядели как отдельные
  люди. Номер окна теперь хранится в `data/presence.json` (локально, никуда не отправляется), а
  обзор показывает пик текущего и предыдущего окна — сколько панелей работало за последние
  десять минут.
- **«Последний релиз» показывал alpha.9, хотя уже вышла alpha.10.** GitHub перечисляет релизы в
  порядке тегов, поэтому `alpha.10` приходит после `alpha.6`. Теперь релизы сортируются по
  версии.

## Как обновиться

Панель обновляет себя сама: «Проверить обновления» → «Установить». Настройки, история, бэкапы и
сценарии в `data/` сохраняются.

Установка с нуля:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

## Качество

- 226 тестов в 21 файле; `npm run typecheck` и `npm run build` проходят.
- Живые проверки: `/api/insights` отдаёт снимок при исчерпанном лимите GitHub; `/api/insights/presence`
  отдаёт `windowSec: 600` и пик двух окон; отметка о своём окне остаётся на диске после перезапуска.
