# Alice Control Center 1.0.0 Alpha 3

Выпуск про обновления. У тестировщика на alpha.1 карточка «Обновления» показывала «нет связи»: его
провайдер не пускает к `api.github.com`, хотя сам GitHub открывается. Панель теперь проверяет релизы
через обычную страницу `github.com`, поэтому обновление находится и на такой сети.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=1.0.0-alpha.3)

## Что исправлено

- **Проверка обновлений без GitHub API.** Если `api.github.com` недоступен, панель запрашивает
  `github.com/<repo>/releases/latest`, берёт тег из адреса после перенаправления и собирает ссылки на
  архив и контрольную сумму по обычному шаблону релиза. Заметки читаются из `docs/release-notes/`
  этого тега. Перед установкой SHA-256 проверяется так же строго, как раньше.
- **Ошибка объясняет, что случилось.** Когда не отвечают оба адреса, вместо общей фразы панель пишет,
  какой код сети пришёл (`ENOTFOUND`, `ETIMEDOUT`, `timeout`), и предлагает проверить интернет или VPN.
  В карточке «Обновления» появилась ссылка на страницу релизов — оттуда можно скачать ZIP вручную.
- **Установщик устойчив к той же блокировке.** `install.ps1` при недоступном API определяет последний
  тег по перенаправлению `github.com/.../releases/latest` и сам собирает адреса архива и `.sha256`.

## Как обновиться

Панель на alpha.2 или новее: «Настройки» → «Обновления» → «Проверить обновления» → «Установить».

Панель на alpha.1, у которой API был заблокирован, ещё не умеет использовать новый путь — её нужно
один раз обновить установщиком:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

Или скачать `Alice-Control-Center-1.0.0-alpha.3.zip` со страницы релизов и распаковать поверх
установки. Настройки, история, бэкапы и сцены в `data/` сохраняются.

## Качество

- 119 тестов в 14 файлах — без изменений; проверка обновлений дополнительно прогнана на живом релизе
  с принудительно заблокированным `api.github.com`: тег, размер архива и заметки совпали с API-ответом.
- `npm run typecheck` проходит, `npm run build` собирает панель как раньше.
