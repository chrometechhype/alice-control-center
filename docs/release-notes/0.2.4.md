# Alice Control Center 0.2.4

Небольшой фикс-релиз: проверка ИИ-модели больше не выбрасывает из панели.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=0.2.4)

## Исправлено

- «Проверить модель» в настройках ИИ показывала экран «Защищённый доступ → Введите токен
  доступа» и разлогинивала панель. Причина: отказ ключа ИИ-сервера отдавался как HTTP 401,
  а frontend трактует любой 401 как истёкшую сессию LAN-доступа.
- Теперь ошибка ключа возвращается как `AI_AUTH` со статусом 502 и понятным текстом, а экран
  токена вызывается только по кодам `UNAUTHORIZED` и `BAD_TOKEN`. Проверка доступа по локальной
  сети работает как раньше.

## Установка

Одной командой в PowerShell:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

Ставит панель в `%LOCALAPPDATA%\AliceControlCenter`, проверяет SHA-256 релиза, создаёт ярлык на
рабочем столе и значок состояния в трее.

## Обновление с 0.2.3

«Настройки» → «Обновления» → «Проверить обновления» → «Установить», или правый клик по значку в
трее → «Проверить обновления». `data/` с настройками, историей и бэкапами не затрагивается.
