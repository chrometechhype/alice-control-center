# Alice Control Center 0.2.3

Обновление про установку и повседневный запуск: одна команда в PowerShell, ярлык на рабочем столе
и значок состояния в трее.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=0.2.3)

## Установка одной командой

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

Установщик проверяет Node.js 20+, скачивает последний релиз, сверяет SHA-256, ставит панель в
`%LOCALAPPDATA%\AliceControlCenter`, сохраняет `data/`, создаёт ярлык на рабочем столе и запускает
панель. Права администратора не нужны.

## Значок в трее

- зелёный — панель работает, станция подключена;
- жёлтый — панель работает, станция не подключена;
- серый — панель остановлена.

Правый клик: открыть, запустить, остановить, перезапустить, проверить обновления, открыть папку
и журнал, скрыть значок, остановить панель и выйти. Двойной клик открывает панель. Ярлык запускает
всё без окна консоли.

## Что ещё

- `start.bat` теперь работает через общий лаунчер и не поднимает вторую копию backend.
- Установщик и скрипты трея входят в ZIP-архив релиза.
- README: разделы про установку одной командой и значок в трее.

## Обновление с 0.2.2

«Настройки» → «Обновления» → «Проверить обновления» → «Установить». Настройки, история, бэкапы и
сцены в `data/` сохранятся. После обновления ярлык и значок продолжают работать.

## Безопасность

- Backend по-прежнему слушает только `127.0.0.1`.
- Установщик принимает архив только с совпадающей SHA-256.
- На станцию ничего не устанавливается.
