# Alice Control Center 0.2.1

Небольшое обновление оформления и проверка системы обновлений.

## Что нового

- Обложка проекта для README и карточки репозитория.
- Версия в боковой панели теперь читается из `package.json` и больше не отстаёт от релиза.
- Инструкции по установке обновлены под актуальный архив.

## Проверка обновлений

Если у вас установлена 0.2.0, панель должна показать баннер «Доступно обновление 0.2.1».
Нажмите «Установить» — ACC скачает ZIP, сверит SHA-256, сделает резервную копию, перезапустится
и откроется уже на 0.2.1. Файлы в `data/` не затрагиваются.

## Установка с нуля

1. Скачайте `Alice-Control-Center-0.2.1.zip` и `Alice-Control-Center-0.2.1.zip.sha256`.
2. Проверьте SHA-256:

   ```bash
   sha256sum -c Alice-Control-Center-0.2.1.zip.sha256
   ```

   Windows:

   ```bat
   certutil -hashfile Alice-Control-Center-0.2.1.zip SHA256
   ```

3. Распакуйте и запустите `start.bat` (Windows) или `./start.sh` (macOS/Linux).
4. Откройте http://127.0.0.1:8722 и пройдите мастер подключения.

Нужен Node.js 20+ и root-SSH на станции. Пароль хранится только в `data/config.json` на вашем
компьютере.

## Безопасность

- Backend по умолчанию слушает только `127.0.0.1`.
- LAN-доступ включается явно и требует токен.
- Опасные операции требуют подтверждения.
- Обновления принимаются только с проверкой SHA-256 и безопасных путей в ZIP.
- Не публикуйте root-SSH и панель в открытый интернет.

Полное описание — в [README](https://github.com/chrometechhype/alice-control-center#readme).
