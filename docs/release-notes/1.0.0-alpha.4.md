# Alice Control Center 1.0.0 Alpha 4

Выпуск про «Сброс». В Fun Lab кнопка «Сброс» после случайного цвета отвечала «эффект сброшен», но
кольцо оставалось цветным: случайный цвет к этому моменту уже был сохранён как «последний цвет
панели», и сброс честно возвращал его же. Теперь панель запоминает состояние кольца *до* эффекта и
возвращает именно его.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=1.0.0-alpha.4)

## Что исправлено

- **«Сброс» действительно сбрасывает.** Перед началом эффекта (случайный цвет, сцена, анимация,
  проверка колец) панель запоминает, как кольцо выглядело до него, и «Сброс» возвращает это
  состояние: прежний цвет панели, выключенное кольцо или штатную индикацию Алисы. Несколько нажатий
  «Случайный цвет» подряд не сдвигают точку возврата — сброс уводит к состоянию до всей серии.
- **Осознанные действия закрывают эффект.** Применение выбранного цвета в LED Studio, «Выключить»,
  «Включить» и «Штатный режим» считаются новым исходным состоянием, поэтому последующий «Сброс» не
  откатывает их.
- **Без связи — честная ошибка.** Если колонка недоступна, «Сброс» сообщает, что кольцо вернуть не
  удалось, вместо зелёного тоста об успехе.

## Как обновиться

«Настройки» → «Обновления» → «Проверить обновления» → «Установить». Панели на alpha.1, где был
заблокирован GitHub API, нужно один раз прогнать установщик:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

Настройки, история, бэкапы и сцены в `data/` сохраняются.

## Качество

- 123 теста в 14 файлах; четыре новых проверяют точку восстановления: возврат вместо цвета эффекта,
  сохранение первой точки при серии нажатий, сброс после осознанного действия и запасной путь без
  эффекта.
- `npm run typecheck` и `npm run build` проходят.
