# Alice Control Center 1.0.0 Alpha 16

Выпуск про доверие к кнопке. В пятнадцатой версии она обещала скачать ffmpeg, писала «Скачиваем…»
и молча возвращалась на место. Теперь скачивание живёт на стороне панели, а не браузера, и
показывает, сколько уже прилетело.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=1.0.0-alpha.16)

## Исправлено

- **Кнопка «Скачать» возвращалась на место.** Загрузка ffmpeg — 170 МБ — висела на открытом
  браузерном запросе и обрывалась вместе с закрытой вкладкой, ушедшим прокси или молча
  переподключившейся сетью. Человек видел «Скачиваем…» и ту же кнопку, без единого слова о причине.
  Скачивание переехало на сервер панели: запрос теперь коротенький, а состояние опрашивается
  отдельно — закрытая вкладка загрузке больше не мешает.
- **Ошибка перестаёт быть молчанием.** Если качание всё-таки не удалось — недоступен интернет,
  архив отдаёт 404, папка `data/tools` не открывается на запись — панель называет причину и
  подсказывает, что сделать.

## Изменено

- **Скачанная копия главнее системной.** Панель сначала смотрит в `data/tools` и только потом в
  PATH. Нажимать «Скачать» идут именно тогда, когда системная версия не работает или её нет, —
  и теперь её действительно получают, а не снова упираются в чужой `ffmpeg` из PATH.
- **Прогресс вместо спиннера.** Во время загрузки видно «Скачиваем 43% из 170 МБ», а не крутящийся
  значок до бесконечности.

## Почему так

Прошлый релиз решал задачу «человек не может поставить ffmpeg сам», но сам делал это хрупко:
целая минута держался открытый HTTP-запрос. На практике этого хватило, чтобы на первом же
пользователее кнопка оказалась хуже, чем её отсутствие.

## Как обновиться

Панель обновляет себя сама: «Настройки» → «Обновления» → «Проверить обновления» → «Установить».
Настройки, история, бэкапы и сценарии в `data/` сохраняются.

Установка с нуля:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

```sh
curl -fsSL https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.sh | sh
```

- 233 теста в 22 файлах; `npm run typecheck` и `npm run build` проходят.
- Проверено вживую: adb скачивается через панель фоном (8 044 989 байт, `Android Debug Bridge
  version 1.0.41`), ffmpeg — 170 МБ (`ffmpeg version N-128212`), оба запускаются из `data/tools`.
- Проверено, что скачанная копия выигрывает у системной: в списке инструментов путь ведёт в
  `data/tools`, а не в PATH.
