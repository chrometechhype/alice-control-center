# Alice Control Center 0.3.0

Главное обновление про связь: колонка находится сама, переподключение больше не упирается в тупик,
а Sound Studio научился озвучивать текст так, что на станции ничего не остаётся.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=0.3.0)

## Новое

- **Поиск колонки в сети.** В «Мастере подключения» кнопка «Найти колонку в сети»: mDNS, таблица ARP
  и опрос портов 22 и 2222 по всем локальным /24. Адрес, порт и пользователь подставляются сами.
- **Переподключение по MAC.** Панель запоминает MAC и device ID станции. Если DHCP выдал новый IP,
  ACC находит колонку по MAC и обновляет сохранённый адрес — править его вручную не нужно.
- **Озвучка.** «Играть на станции» проигрывает системный звук прямо на колонке, «Сказать на колонке»
  синтезирует речь через `/audio/speech`, играет клип из `/tmp` и удаляет его той же командой.
  Модель и голос озвучки — в «Настройки» → «ИИ-генератор».
- **Доступ с телефона при раздаче Wi-Fi.** Карточка показывает адреса всех интерфейсов и помечает
  нужный «сеть колонки», есть диагностика брандмауэра Windows и кнопка «Разрешить порт в брандмауэре».
- **Описание релиза.** Баннер и карточка «Обновления» показывают, что изменилось, дату релиза и
  размер архива вместо сырого markdown.

## Исправлено

- **Вечное переподключение.** Параллельные попытки подключения сериализованы, после четырёх быстрых
  попыток панель не сдается, а ищет колонку каждые 45 секунд.
- **Ложный баннер обновления.** «Установлено 0.2.3 / Последняя 0.2.3» с кнопкой «Установить 0.2.3» —
  статус теперь считается по живой версии.
- **Ровные обложки сцен** в Fun Lab: одна высота превью, заголовок и описание не разъезжаются.
- **Генерация сцен с первого раза.** ИИ присылает короткий рецепт сцены (эффект, палитра, fps),
  кадры считает панель. Текст рассуждений перед JSON, оборванный ответ и продублированный пример
  больше не ломают генерацию; если и это не помогло — одна автоматическая повторная попытка.

## Интерфейс

Название панели живёт в боковой панели, вторая копия заголовка из топбара убрана. Разделы
сгруппированы как «Обзор», «Станция», «Инструменты», «Панель», карточки настроек идут в порядке
подключение → телефон → интерфейс → образ станции → ИИ → обновления. Из героя обзора убраны дубли,
которые повторяли карточки метрик и «Устройство».

## Обновление с 0.2.4

«Настройки» → «Обновления» → «Проверить обновления» → «Установить», или правый клик по значку в
трее. Настройки, история, бэкапы и сцены в `data/` сохранятся.

## Безопасность

- Backend по умолчанию слушает только `127.0.0.1`, LAN-доступ включается вручную и всегда под токеном.
- Озвучка ничего не записывает в библиотеку станции: клип живёт в `/tmp` ровно столько, сколько играет.
- Правило брандмауэра добавляется только для частной сети и только после явного подтверждения.
