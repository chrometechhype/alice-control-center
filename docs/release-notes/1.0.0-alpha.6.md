# Alice Control Center 1.0.0 Alpha 6

Выпуск про то, что видно каждый день: тёмная тема стала по-настоящему графитовой, Wi-Fi работает
через `wpa_supplicant` и показывает пароль на главном экране, связанные шаги сценария срабатывают
одновременно, а для разбора падений появилась полная отладка одной командой.

![Alice Control Center](https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/docs/cover.png?v=1.0.0-alpha.6)

## Что нового

- **Графитовая тёмная тема.** Подложка `#0b0c0e`, карточки `#131417`, боковое меню и топбар без
  синевы и фиолетового оттенка. Причина «посветлевшей» темы тоже найдена: блок акцента корпуса и
  `[data-theme='dark']` имели одинаковую специфичность, и светлые подложки с примесью акцента
  перекрывали графит. Теперь акцент остаётся только в кнопках и иконках.
- **Wi-Fi на главном экране.** Карточка обзора показывает сеть, к которой подключена станция, и её
  настоящий пароль (`psk`) из `/bkupgrade/data/wpa_supplicant.conf`. Пароль скрыт за «глазом»,
  копируется одной кнопкой; рядом — IP, шифрование, частота и путь к конфигу.
- **Вкладка Wi-Fi на `wpa_cli`.** Сканирование эфира, подключение к новым точкам и переключение
  сети перезаписью конфига с `wpa_cli -i wlan0 reconfigure` — без перезагрузки. Чужие блоки
  `network={…}` сохраняются байт в байт; если `wpa_cli` нет, вкладка честно говорит об этом.
- **Сценарий: до 32 шагов.** У каждого шага есть «Выполнять одновременно с шагом N»: связанные шаги
  стартуют в одном тике, поэтому кольцо и голос звучат вместе, без задержки.
- **Озвучка голосом Алисы.** «Сказать» и шаг сценария `say` произносят текст штатным голосом
  станции: фраза уходит в её локальный речевой сервис по SSH, синтезируется в облаке Яндекса и
  играет через её собственный плеер. Сторонний TTS, голос Windows и ключи озвучки больше не нужны;
  файлы на станции не создаются. Конец фразы панель видит по состоянию речи станции, поэтому
  прозвучавшая фраза больше не показывается как таймаут.
- **LED Studio.** Кольцо зоны само открывает системный выбор цвета, под ним виден HEX. Пресет
  применяется как эффект, и «Сброс» возвращает цвет, который был до него.
- **Bluetooth.** Подключение к отдельному устройству больше не падает молча: панель регистрирует
  агент BlueZ, делает `trust`, при необходимости `pair`, затем `connect` и проверяет результат по
  `info`; при `host is down` один раз сканирует эфир и повторяет попытку.
- **Станция Мини 2 с часами (#1).** Модель определяется правильно. Для LED-дисплея и часов панель
  объясняет, что ими управляет прошивка, а не обещает управление, которого нет.

## Полная отладка

```bat
start.bat --full-debug
```

```bash
npm run debug:full
./full-debug.sh --full-debug
```

Отчёт сохраняется в `data/reports/full-debug-<дата>.txt` и содержит журналы ядра и демонов, ошибки и
OOM, процессы Quasar и YAM, дамп ОЗУ, скорость диска через `dd`, сеть, Bluetooth и
`wpa_supplicant.conf`. Пароли Wi-Fi маскируются, пароль SSH не печатается.

## Как обновиться

Начиная с alpha.5 панель обновляет себя сама: «Проверить обновления» → «Установить». Настройки,
история, бэкапы и сцены в `data/` сохраняются.

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```
