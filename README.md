# Alice Control Center

![Alice Control Center](docs/cover.png?v=0.2.4)

Локальная панель управления рутованной Яндекс Станцией с компьютера или телефона — для всей
линейки станций с Алисой, от первой Лайт до Дуо Макс.
Vue 3 + TypeScript на фронтенде, Node.js + Express на backend, связь со станцией — по SSH.
Браузер никогда не подключается к станции напрямую, не видит root-пароль и не хранит его.

## Что умеет

- **Setup Wizard** — проверка SSH, определение модели и возможностей, сохранение подключения.
- **Обзор** — состояние, модель, прошивка, метрики, громкость, быстрые действия.
- **Системный монитор** — CPU, память, температура, Wi-Fi, диски, процессы, fastfetch-подобная сводка.
- **Sound Studio** — список системных звуков, замена с автоматическим бэкапом, восстановление.
- **LED Studio** — цвет по зонам, готовые эффекты, произвольный FPS до 60, анимация выполняется на самой колонке.
- **Bluetooth** — сканирование, сопряжение, подключение, удаление устройств и режим поиска для телефона.
- **Файлы** — просмотр и загрузка только в разрешённые каталоги.
- **Терминал** — только команды из белого списка, опасные операции требуют подтверждения.
- **Бэкапы** — конфигурация панели и файлы станции, проверка SHA-256, восстановление.
- **Автоматизация** — локальные сценарии из разрешённых действий.
- **Fun Lab** — готовые LED-сцены и ИИ-генератор через любой OpenAI-совместимый сервер: модель сама подбирает FPS и рисует кадры.
- **Event Center** — журнал операций с очисткой секретов.
- **Плагины и YAM** — просмотр состояния, без установки случайных бинарников.
- **Обновления** — проверка релизов GitHub, SHA-256, резервная копия и откат при ошибке.
- **Установка и трей** — установка одной командой, ярлык на рабочем столе, значок состояния с запуском и остановкой панели.
- **Оформление** — Material You 3 Expressive, светлая/тёмная/системная тема, динамические акценты под цвет корпуса Алисы.
- **Приветствие** — пошаговое знакомство, контакт автора в Telegram.

## Поддерживаемые станции

Панель рассчитана на всю линейку Яндекс Станций с Алисой. Модель определяется автоматически по
hostname/model при подключении: для неё показывается официальное изображение и подбирается акцентный
цвет интерфейса.

| Семейство | Модели |
| --- | --- |
| Лайт | Лайт, Лайт 2 |
| Мини | Мини, Мини 3, Мини 3 Про, Мини с часами |
| Макс | Макс |
| Станция | Станция 2, Станция 3, Дуо Макс, Миди, Стрит |

Все 12 моделей поддерживаются в интерфейсе и используют общий SSH-адаптер. Полный набор функций
проверен на Станции Лайт 2 (`Yandex Prune EVT2`); на остальных доступность LED, Bluetooth,
системных звуков и отдельных путей зависит от прошивки. Если модель не распознана, показывается
общий образ станции — подключение и диагностика продолжают работать.

## Архитектура

```
Браузер (Vue 3, localhost:5173 или backend:8722)
        │  HTTP / WebSocket (локально; для телефона — токен)
        ▼
Backend (Node + Express, 127.0.0.1:8722, data/config.json)
        │  allowlist, zod, подтверждения, журнал
        ▼
StationAdapter (SSH, root@station:2222)
        ▼
Яндекс Станция (BusyBox, sysfs, /data, /system/vendor/quasar)
```

Backend по умолчанию слушает только `127.0.0.1`. Доступ с телефона включается явно в настройках,
при включении LAN-доступа требуется токен. Пароль SSH и ключи ИИ хранятся только в
`data/config.json` с правами `0600`, не попадают во frontend и в журнал.

## Быстрый старт

### Установка одной командой (Windows)

Откройте PowerShell и вставьте:

```powershell
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

Установщик:

- проверяет Node.js 20+ и при отсутствии предлагает поставить LTS через `winget`;
- скачивает последний релиз GitHub и сверяет SHA-256 — без контрольной суммы установка
  отменяется;
- ставит панель в `%LOCALAPPDATA%\AliceControlCenter`, сохраняя `data/` при обновлении;
- создаёт ярлык «Alice Control Center» на рабочем столе;
- запускает панель на `http://127.0.0.1:8722` и значок состояния в трее.

Права администратора не нужны. Другую папку можно задать перед запуском:

```powershell
$env:ACC_INSTALL_DIR = 'D:\Apps\AliceControlCenter'
irm https://raw.githubusercontent.com/chrometechhype/alice-control-center/main/install.ps1 | iex
```

### Значок в трее

Ярлык запускает панель без окна консоли и показывает значок в области уведомлений:

| Значок | Состояние |
| --- | --- |
| зелёный | панель работает, станция подключена |
| жёлтый | панель работает, станция не подключена |
| серый | панель остановлена |

Правый клик — открыть, запустить, остановить или перезапустить панель, проверить обновления,
открыть папку и журнал, скрыть значок. Двойной клик открывает панель. «Скрыть значок» оставляет
backend работать, «Остановить панель и выйти» завершает и панель, и значок.

### Готовый архив

1. Скачайте `Alice-Control-Center-0.2.4.zip` и `Alice-Control-Center-0.2.4.zip.sha256`
   со страницы [Releases](https://github.com/chrometechhype/alice-control-center/releases/latest).
2. Сверьте контрольную сумму:

   Windows:

   ```bat
   certutil -hashfile Alice-Control-Center-0.2.4.zip SHA256
   ```

   macOS/Linux:

   ```bash
   sha256sum -c Alice-Control-Center-0.2.4.zip.sha256
   ```

3. Распакуйте архив в любую папку и запустите:
   - Windows: `start.bat`
   - macOS/Linux: `./start.sh`

Скрипт установит зависимости, соберёт frontend при необходимости и запустит backend на
`http://127.0.0.1:8722`. Папка `data/` создастся при первом запуске.

Требования: Node.js 20+ и npm, станция с включённым root-SSH в локальной сети.
SFTP не требуется: панель работает через shell-каналы.

### Из исходников

```bash
npm install
npm run dev
```

- Frontend: http://localhost:5173
- Backend: http://127.0.0.1:8722
- Vite проксирует `/api` и `/ws` на backend.

Production-сборка:

```bash
npm run build
npm start
```

После сборки backend отдаёт `dist` и API на одном порту: http://127.0.0.1:8722.
Порт можно изменить переменной `ACC_PORT`.

### Первое подключение

1. Откройте «Мастер подключения».
2. Укажите IP станции, SSH-порт (обычно `2222`), пользователя `root` и пароль.
3. Нажмите проверку: панель подключится, определит модель, прошивку и доступные модули.
4. Сохраните подключение.

Пароль сохраняется только на этом компьютере в `data/config.json`. В исходниках и публичном
архиве его нет.

### Доступ с телефона

1. «Настройки» → «Доступ по локальной сети» → включить.
2. Сгенерируйте/покажите токен и QR-код.
3. Откройте панель по адресу компьютера в той же Wi-Fi-сети и введите токен.

LAN-доступ всегда защищён токеном. Выключайте его, когда он не нужен.

## Обновления

Панель проверяет последний релиз GitHub при запуске (кэш — 15 минут) и показывает баннер, если
доступна новая версия. Ручная проверка — «Настройки» → «Обновления».

Установка:

1. Панель скачивает ZIP-архив релиза по HTTPS.
2. Проверяет SHA-256 из `asset.digest` GitHub или из файла `.sha256` рядом с архивом.
3. Распаковывает архив во временную папку и проверяет версию в `package.json`.
4. Сохраняет резервную копию файлов панели в `data/updates/backup-*`.
5. Запускает `scripts/apply-update.mjs`, который останавливает старый backend, копирует файлы,
   при необходимости обновляет зависимости и запускает новый backend.
6. При ошибке возвращает предыдущую версию. Папка `data/` не затрагивается.

Если у релиза нет контрольной суммы, установка отменяется. Архивы с небезопасными путями,
слишком большим размером или несовпадающей версией отклоняются. Обновление можно запустить
вручную из ZIP-архива: распакуйте его поверх папки панели, сохранив `data/`, и запустите
`start.bat` или `start.sh`.

Репозиторий проверки можно переопределить переменной `ACC_GITHUB_REPO=owner/repo`; для приватных
форков доступен `ACC_GITHUB_TOKEN`. Обе переменные читаются только на backend.

> Не запускайте панель под менеджером, который сам перезапускает процесс во время обновления:
> старый и новый backend могут одновременно занять порт. `start.bat` и `start.sh` этого не делают.

## Bluetooth

- Сканирование ограничено 20 секундами и выполняется через `bluetoothctl`.
- «Подключить» сначала пробует `pair`, затем `connect` и `trust`. Если устройство требует PIN,
  завершите сопряжение на самом устройстве: ACC не вводит PIN за вас.
- «Режим поиска» включает `discoverable on` и `pairable on`, чтобы телефон увидел станцию.
  Выключение возвращает `discoverable off` и `pairable off`.
- «Забыть» удаляет устройство из списка после подтверждения.
- Выключение адаптера требует подтверждения и может прервать работу пульта или приложения колонки.
- На некоторых прошивках набор команд или имена адаптеров отличаются. Панель показывает вывод
  `bluetoothctl` и не имитирует недоступные функции.

## Безопасность

Правила, на которых построен проект:

- По умолчанию backend слушает только `127.0.0.1`.
- Доступ с телефона включается явно в настройках.
- При включении LAN-доступа требуется авторизация.
- Не сохраняй пароли в исходном коде.
- Не копируй приватные ключи в проект.
- Не сохраняй секреты в frontend.
- Не добавляй пароли в URL.
- Не выполняй произвольные shell-команды через незащищённый HTTP endpoint.
- Проверяй пути файлов от обхода каталогов.
- Не публикуй root-доступ, SSH или ADB в открытый интернет.
- Не перезапускай всю станцию автоматически.
- Все потенциально опасные операции должны требовать подтверждения.
- Не скачивай и не запускай случайные бинарники.
- Не устанавливай ничего на колонку без необходимости.

Дополнительно: CSP и security-заголовки, zod-валидация, белый список команд и путей, лимит
размера загрузок, проверка magic-байтов, очистка журнала от секретов. Подробнее — [SECURITY.md](SECURITY.md).

## Совместимость

- Полный набор функций проверен на Яндекс Станции Лайт 2 (`Yandex Prune EVT2`, прошивка
  `0.372.1.13`, kernel `4.9.113`, BusyBox 1.31.1).
- Остальные модели линейки определяются автоматически и работают через тот же SSH-адаптер.
- SSH без SFTP (shell fallback), BusyBox `sh`, `usleep`, `awk`, `sha256sum`.
- Светлая, тёмная и системная темы; динамические акценты по цвету корпуса.

## Не поддерживается / не гарантируется

- Установка сторонних APK, прошивок, модулей ядра и случайных бинарников.
- Прямое управление ADB из браузера.
- Публикация панели в интернет, root-доступ без токена.
- Автоматический перезапуск станции.
- Цвет корпуса и наличие часов нельзя прочитать программно: панель использует сохранённый выбор
  пользователя (по умолчанию — зелёный, без часов) и подстраивает акценты.
- На некоторых прошивках Bluetooth-команды или отдельные sysfs-узлы могут отличаться.
- 60 FPS — экспериментальный режим: кольцо может обновляться неравномерно, а долгая нагрузка
  способна перегрузить LED-контроллер. Для длительных сцен используйте 20–30 FPS.
- Во время стресс-теста 60 FPS станция один раз перезагрузилась через несколько минут. Причина
  не подтверждена; панель сама станцию не перезапускает. Учитывайте это при долгих анимациях.
- Панель не является официальным продуктом Яндекса.

## Бэкапы и восстановление

- Замена системного звука автоматически создаёт бэкап оригинала.
- «Бэкапы» → создать бэкап конфигурации панели или выбранных файлов станции.
- Каждый файл проверяется по SHA-256 при создании и восстановлении.
- Восстановление пишет файл на станцию, выставляет права и повторно сверяет хеш.
- Файлы бэкапов лежат в `data/backups/` и не попадают в общий архив проекта.
- Обновления панели складывают резервные копии в `data/updates/` и хранят три последние.

## Внешний вид и цвета

- «Настройки» → «Образ станции»: цвет корпуса (зелёный, лавандовый, синий, розовый, коралловый,
  серый) и часы.
- Выбор сохраняется в браузере (`localStorage`) и не меняет настройки колонки.
- Акценты, фоны, карточки, кнопки, навигация и логотип подстраиваются под цвет Алисы через
  CSS `color-mix`.
- Для моделей без кастомизации показывается официальное изображение, акценты берутся из палитры модели.
- Приветствие можно открыть повторно: «Настройки» → «Приветствие» → «Показать».

## Fun Lab и LED

- Сцены отправляются на станцию одним запросом.
- Backend генерирует shell-скрипт, записывает его в `/tmp/acc-led-anim.sh` и запускает через `nohup`.
- Кадры пишутся в sysfs на самой колонке, без SSH-канала на каждый кадр — соединение остаётся стабильным.
- Остановка — через PID-файл и stop-файл; после остановки можно вернуть штатный триггер `led_ring_fb`.
- Переключатель «Работать без таймаута» повторяет сцену бесконечно — и для готовых, и для своих
  сохранённых сцен. Выключение — кнопками «Выключить» или «Штатный режим».
- Свои сохранённые сцены выводятся отдельным блоком «Мои сцены» над готовыми сценами.
- «ИИ-генератор» работает только через OpenAI-совместимый сервер, выбранный в настройках.
  Модель получает описание и сама возвращает название, FPS и RGB-кадры; backend проверяет
  диапазоны, количество кадров и зон, после чего сохраняет сцену в «Мои сцены».
- Встроенные пресеты: OpenAI, OpenRouter, Groq, Pollinations без ключа (около одного запроса в
  30 секунд), локальные Ollama и LM Studio. В режиме «Свой сервер» можно вручную указать base URL,
  модель и ключ.
- Описание сцены уходит только на выбранный вами сервер. Не пишите в него пароли и личные данные.
  API-ключ остаётся на backend.
- Пресеты сохраняются в `data/led-presets.json` на компьютере.

## Известные ограничения

- SFTP на станции отсутствует; запись больших файлов идёт через shell и ограничена таймаутами.
- Некоторые операции требуют root; панель не повышает привилегии и не обходит ограничения прошивки.
- Метрики обновляются с выбранным интервалом (по умолчанию 5 с), это не realtime-мониторинг.
- При обрыве Wi-Fi возможны переподключения; статус виден в шапке и Event Center.
- ИИ-генератор зависит от выбранного сервера и интернета (кроме локальных Ollama/LM Studio).
  Качество сцены определяется моделью; при ошибке панель показывает причину и не подменяет
  результат локальным алгоритмом.
- Проверка обновлений обращается к GitHub. При отсутствии интернета панель показывает ошибку,
  но продолжает работать.
- Панель не является официальным продуктом Яндекса.

## Разработка и релизы

```bash
npm run dev        # backend + Vite
npm run build      # vue-tsc + production build
npm test           # unit-тесты
npm run package    # release/alice-control-center + ZIP + SHA-256
```

Версия хранится в `package.json`. Релиз публикуется тегом `vX.Y.Z`: workflow
[release.yml](.github/workflows/release.yml) собирает проект, запускает тесты, упаковывает
`release/Alice-Control-Center-X.Y.Z.zip` и прикладывает архив с `.sha256` к GitHub Release.

```bash
npm version patch
git push --follow-tags
```

Если релиз создаётся вручную:

```bash
npm run build
npm run package
gh release create v0.2.4 release/Alice-Control-Center-0.2.4.zip \
  release/Alice-Control-Center-0.2.4.zip.sha256 \
  --title "Alice Control Center 0.2.4" \
  --notes-file docs/release-notes/0.2.4.md
```

Список изменений — [CHANGELOG.md](CHANGELOG.md).

## Структура

```
server/        Express backend, SSH-адаптер, allowlist, бэкапы, LED, обновления
shared/        общие типы
src/           Vue-приложение, компоненты, стили, store
public/        официальные изображения станций, аватар Telegram
tests/         unit-тесты парсеров, безопасности, определения модели
scripts/       apply-update.mjs, упаковка релиза, служебные скрипты
docs/          технические заметки, тизер, release notes
data/          создаётся при запуске: config.json, бэкапы, журнал (не коммитить)
```

## Диагностика

- «Event Center» — последние операции и ошибки.
- «Системный монитор» — нагрузка, температура, Wi-Fi RSSI.
- Проверка SSH: «Мастер подключения» → проверить соединение.
- Если backend не стартует, проверьте, что порт `8722` свободен (`ACC_PORT` меняет порт).
- Логи backend выводятся в консоль процесса `npm run dev` / `npm start`.
- Логи обновления: `data/updates/last-update.log` и `data/logs/update-process.log`.
